# Pockets Vault public pages

Static, dependency-free support and privacy pages for App Store and Play Store metadata.

## Public paths

- English support: `/support/`
- Italian support: `/support/it/`
- Spanish support: `/support/es/`
- English privacy: `/privacy/`
- Italian privacy: `/privacy/it/`
- Spanish privacy: `/privacy/es/`

The directory can be published directly with GitHub Pages or any static hosting provider. All pages must remain publicly accessible over HTTPS without authentication.
