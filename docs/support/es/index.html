¿Cómo hago una copia de seguridad?

Abre Ajustes y usa Exportar copia de seguridad. Guarda de forma segura el archivo generado y su contraseña. Para restaurarlo, selecciona Importar copia de seguridad. Las copias pueden contener información financiera sensible.

⌁

No puedo desbloquear la aplicación

Prueba tu PIN si Face ID o los datos biométricos no están disponibles. Los ajustes biométricos dependen de iOS o Android. Por seguridad, Pockets Vault no puede recuperar un PIN local olvidado.

◎

El escaneo del recibo es impreciso

Usa un recibo plano y bien iluminado, con el total visible. Revisa siempre comercio, importe, fecha y categoría antes de guardar; todos los valores extraídos se pueden editar.

€

¿Cómo funciona la conversión de divisas?

La aplicación descarga los tipos de referencia del Banco Central Europeo y los guarda localmente. La fecha del tipo aparece en Ajustes. Las transacciones existentes conservan la conversión guardada.

⟳

Faltan datos después de actualizar

No desinstales la aplicación: al hacerlo se elimina la base de datos local. Reinicia el dispositivo y contacta con soporte indicando la versión de la aplicación y de iOS o Android.

×

¿Cómo elimino mis datos?

Puedes eliminar elementos individuales dentro de la aplicación. Al desinstalar Pockets Vault se eliminan la base de datos y los recibos locales, pero no las copias exportadas a otros lugares.

Contacta con el desarrollador

¿Aún necesitas ayuda?

Escríbenos indicando la versión de la aplicación, el modelo del dispositivo y los pasos para reproducir el problema. Elimina números de cuenta y datos financieros sensibles de las capturas.
